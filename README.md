# Sakura Shell 2

Una shell de linux personalizada y aun en procesos, si gustas aportar y decirme mis errores, gracia <3

## Cosillas

- Archivos de Hyprland con lua
- Generacion de colores usando Matugen (fue horrible, la ia me ayudo en esto perdon)
- Seleccion de wallpapers impulsado por Wallpick.
- Imagenes y Videos se pueden poner. (que por cierto tampoco me acuerdo)
- Extraccion automatica de frames usando FFmpeg.
- Waybar.
- Wofi.
- Impulsado por algunos recursos de sakura shell 2.

## Cosas que usa

- CachyOS / Arch Linux
- Hyprland
- Quickshell
- Wallpick
- Matugen
- Waybar
- Wofi
- FFmpeg
- GTK

## Como funciona la extraccion de colores, para mas info md a mi dc

1. Wallpick selecciona un wallpaper..
2. El wallpaper se aplica.
3. FFmpeg extrae un frame para identificar el video o imagen.
4. Matugen genera una paleta de colores chulos.
5. Waybar y Wofi detectan la configuracion y lo usan.
